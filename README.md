# Connect Maldives

A community website to help people living in the Maldives overcome loneliness.

## Features

- Home page with two clear options (lonely / volunteer)
- Simple registration form (no ID or work permit required)
- Safety Guidelines
- Privacy Policy
- About page
- Fully mobile responsive

## How to Run

1. Keep all files in the same folder
2. Open `index.html` in your browser
3. Or upload the folder to Netlify / GitHub Pages / Vercel for free hosting

## Free Hosting Suggestion

- [Netlify Drop](https://app.netlify.com/drop) → just drag the folder
- GitHub Pages
- Vercel

## Note

This is a **frontend demo**.  
Registration data is saved in the browser's localStorage only.  
For a real site you will need a backend, database and proper authentication later.
